# DSH Codex UI

面向 DeepSeek Harness 的 Codex 风格界面插件，包含头像菜单、界面布局与独立更新中心。

本仓库用于发布插件安装包、更新清单与版本说明。各插件保持独立版本，使用 GitHub Releases 分发。

## 独立更新中心

当前发布包含主界面 `@local/codex-account-menu@0.6.22` 与独立更新中心 `@local/codex-update-center@0.1.1`。

主界面提供 Codex 风格布局、头像菜单、临时侧聊和鲸鱼形象设置。`0.6.22` 修复输入区隐藏或等待选择时聊天列宽归零、内容不可见的问题；只在测到正宽度时更新聊天宽度，隐藏时保留上次有效值。“设置 → Codex UI”提供下一句预测的开关与模型设置；预测执行需要另装 `@local/codex-prompt-suggestions` 0.4.0，本 Release 不含该独立插件，缺少时会明确显示未安装。

- 有更新时在左栏头像上方显示橙色入口；无更新或全部安装完成后隐藏。
- 默认自动检查和下载；安装需要用户明确选择。
- 可从“设置 → 更新中心”手动检查，并配置来源为 `Math-rookie/dsh-codex-ui`。
- 每次安装前生成兼容性报告；失败项阻止安装，未验证项目需要明确确认。

从 Release 下载 `.tgz`，在 DeepSeek Harness 的插件管理界面安装。每个正式 Release 同时提供 `update-manifest.json` 和清单列出的安装包，包含对应 SHA-256。

已安装更新中心的用户可直接检查并更新主界面；首次使用时先手动安装更新中心 0.1.1。安装前先处理内存中的临时侧聊，并确认当前没有运行或待确认的会话。报告有未验证项目时，需要展开查看并明确勾选继续。

`0.1.1` 修复 GitHub HTTP 压缩响应的长度校验，并通过官方资源 API 下载清单与安装包。`0.1.0` 使用者需先从最新 Release 手动安装此修复包。

## 兼容性与验证范围

当前基线为 Harness `0.2.1-rc.2`，构建 `332895e0f7c9d4dbfb29729f5eb367fa263ff986`。

`0.6.22` 的冻结包已通过 10 项实际 Chromium 渲染回归和 7 项独立 Electron 启动检查。渲染回归直接运行包内函数与样式，覆盖输入区隐藏、首次隐藏、等待选择时的消息可读与按钮焦点/点击、恢复、缩放和释放；聊天数据与等待状态为明确的人工夹具，不调用模型。相同检查在旧版 `0.6.21` 上复现列宽为 0。

包大小为 18,922,100 字节，SHA-256 为 `f54f87add4851e5e5df1c3a4cbeac1bcb1eb453e467d027ff83c2e30a5bb70d2`。本次已通过真实 GitHub 完成 `0.6.21 → 0.6.22` 的检查、自动下载、摘要校验、展开兼容性报告、明确勾选与官方管理器安装，结果为 `applied`。冷启动保留版本与安装回执，再次联网无更新时入口隐藏；新版本预检 7 项、真实升级 17 项、冷启动 10 项全部通过。在线安装后的包再次通过相同 10 项渲染回归。历史版本的记录单独保留。

本次验收的 GitHub API 使用测试进程专属直连，资源 CDN 沿用既有代理；此前代理出口曾遇到匿名 API 限流。验证没有修改系统代理、日常 profile 或官方程序文件。兼容性报告采用静态预检和发布声明，完整聊天与模型回归、数据迁移及完整恢复仍会标为未验证。

`0.6.21` 的上述列宽问题已在 `0.6.22` 修复。旧 Release 和安装包保持原字节；建议通过更新中心升级。修复不代表完整聊天、模型调用和数据迁移已经完成回归。

从本更新中心发起的安装必须先查看报告；官方原生更新入口保持其原有行为。隔离开发环境不会启动官方桌面安装器。
