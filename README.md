# DSH Codex UI

面向 DeepSeek Harness 的 Codex 风格界面插件，包含头像菜单、界面布局与独立更新中心。本仓库发布安装包、更新清单和版本说明，各插件保持独立版本。

## 当前版本

| 插件 | 版本 | 说明 |
| --- | --- | --- |
| `@local/codex-account-menu` | 0.6.23 | 四角统一，聊天页右侧与底部留白由 4 缩至 2 CSS 像素 |
| `@local/whale-fantasy-compat` | 0.2.2 | 约束背景绘制范围，保持标题栏与图标栏清晰 |
| `@local/codex-update-center` | 0.1.1 | 独立检查、下载、兼容性报告与确认安装，包与上一版相同 |

主界面提供 Codex 风格布局、头像菜单、临时侧聊和鲸鱼形象设置。0.6.23 修复圆角缺口中的深蓝方块及重叠弧线，保持右侧面板内部接缝平直；右侧、底部留白减半。浏览器等卡片打开时继续沿用既有铺满视口的行为，关闭后恢复 2px 留白。继承 0.6.22 的输入区隐藏／等待选择宽度保护。

## 更新方式

- 有更新时，左栏头像上方显示橙色入口；无更新或安装完成后隐藏。
- 默认自动检查和下载，安装需要明确选择。
- “设置 → 更新中心”可手动检查，仓库填写 `Math-rookie/dsh-codex-ui`。
- 每次安装前生成报告。失败项阻止安装，未验证项目需要展开查看并明确确认。

从 [Releases](https://github.com/Math-rookie/dsh-codex-ui/releases) 下载 `.tgz`，通过 Harness 插件管理器首次安装。已有更新中心的用户可直接检查更新。0.1.0 用户需先手动安装更新中心 0.1.1 的下载修复包。

已有鲸鱼背景适配插件时，先更新适配插件 0.2.2，再重新检查并查看新报告，更新主界面 0.6.23。更新中心只更新已安装插件，不会因清单额外列出适配插件而自动新增它。安装前先处理内存中的临时侧聊，确认没有运行或待确认的会话。

“设置 → Codex UI”含下一句预测开关与模型设置；执行依赖单独的 `@local/codex-prompt-suggestions`，本 Release 不含该插件。

## 验证范围

基线为 Harness `0.2.1-rc.2`，构建 `332895e0f7c9d4dbfb29729f5eb367fa263ff986`。

0.6.23 冻结包已在独立实际 Electron 窗口验收：6 种布局组合、1728 个圆角外侧像素样本、48 项背景开关与布局检查、288 帧项目栏切换，视频持续正常播放；浏览器卡片停靠、全屏与关闭恢复通过。原有输入区隐藏、等待选择等 10 项真实 Chromium 渲染回归通过。测试会话和等待状态为人工夹具，没有调用模型。

主界面包为 18,922,041 字节，SHA-256：`404a842a8534d89f97b644b39f9f18edb267e3f77dd3d5d65943d402b2b40ec5`。相对正式 0.6.22，仅嵌入的边框样式及包版本改变，其他 39 个文件和可执行业务逻辑相同；未纳入并行开发中的修改。更新清单提供每个安装包的摘要。

兼容性报告采用静态预检、版本组合及发布声明。完整模型业务、数据迁移和完整恢复仍显示未验证，局部界面验收不代表全面兼容。从本更新中心发起的安装必须先查看报告；官方原生更新入口保持其原有行为。项目隔离环境不会运行官方桌面安装器。

检查和下载使用公开 GitHub API，不使用发布者令牌。匿名 API 限流或网络错误会如实显示。测试仅对当前进程设置 API 直连，资源 CDN 沿用既有代理，没有修改系统代理。

历史 Release 与安装包保留原字节，0.6.22 的原有升级和冷启动记录单独保留。

## 本机更新中心升级验收

发布后已在三个使用环境完成真实 GitHub 检查、自动下载、报告查看、明确确认和官方管理器安装：三份主界面均从 0.6.22 升至 0.6.23，原有两份背景适配均从 0.2.1 升至 0.2.2，共 5 次安装均返回 applied。无适配插件的预测环境没有额外安装它。

更新适配插件后重新检查并生成主界面报告，绑定新环境；安装文件逐一匹配发布摘要。再次联网候选均为 0，头像上方更新入口隐藏，三个页面右侧及底部均实测 2px。会话位置、草稿和核对的预测／桌宠偏好保留。常用与预测环境另在当前聊天执行输入区隐藏／恢复；桌宠环境保留原上下文页，未在该页执行聊天隐藏检查。本次未对模型调用、全量数据库、迁移及完整恢复作验收。

桌宠旧进程检查曾遇到匿名 API 限流；在确认任务、草稿和临时侧聊为空后正常重开，仅对该进程使用 API 直连重试通过。预测环境安装后的首次界面读数遇到插件重载过渡，等待界面就绪后复核通过，没有重复安装。
