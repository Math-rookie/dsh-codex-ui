# DSH Codex UI

面向 DeepSeek Harness 的 Codex 风格界面插件，包含头像菜单、界面布局与独立更新中心。

本仓库用于发布插件安装包、更新清单与版本说明。各插件保持独立版本，使用 GitHub Releases 分发。

## 独立更新中心

当前发布包为 `@local/codex-update-center@0.1.1`。主界面插件将在对应版本验收完成后发布。

- 有更新时在左栏头像上方显示橙色入口；无更新或全部安装完成后隐藏。
- 默认自动检查和下载；安装需要用户明确选择。
- 可从“设置 → 更新中心”手动检查，并配置来源为 `Math-rookie/dsh-codex-ui`。
- 每次安装前生成兼容性报告；失败项阻止安装，未验证项目需要明确确认。

从 Release 下载 `.tgz`，在 DeepSeek Harness 的插件管理界面安装。每个正式 Release 同时提供 `update-manifest.json` 和清单列出的安装包，包含对应 SHA-256。

`0.1.1` 修复 GitHub HTTP 压缩响应的长度校验，并通过官方资源 API 下载清单与安装包。`0.1.0` 使用者需先从最新 Release 手动安装此修复包。

## 兼容性与验证范围

当前基线为 Harness `0.2.1-rc.2`，构建 `332895e0f7c9d4dbfb29729f5eb367fa263ff986`。

更新通知、设置入口、自动下载、报告展示、真实插件管理器安装与生命周期已在独立 Electron 环境验证。首版兼容性报告采用静态预检和发布声明，目标版本完整运行回归、数据迁移及完整恢复仍会标为未验证。

从本更新中心发起的安装必须先查看报告；官方原生更新入口保持其原有行为。隔离开发环境不会启动官方桌面安装器。
