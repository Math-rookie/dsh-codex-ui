# DSH Codex UI

面向 DeepSeek Harness 的 Codex 风格界面插件，包含头像菜单、界面布局与独立更新中心。本仓库发布安装包、更新清单和版本说明，各插件保持独立版本。

## 当前版本

| 插件 | 版本 | 说明 |
| --- | --- | --- |
| `@local/codex-account-menu` | 0.6.23 | 四角统一，聊天页右侧与底部留白由 4 缩至 2 CSS 像素 |
| `@local/whale-fantasy-compat` | 0.2.2 | 约束背景绘制范围，保持标题栏与图标栏清晰 |
| `@local/codex-update-center` | 0.1.1 | 独立检查、下载、兼容性报告与确认安装，包与上一版相同 |

主界面提供 Codex 风格布局、头像菜单、临时侧聊和鲸鱼形象设置。0.6.23 修复圆角缺口中的深蓝方块及重叠弧线，保持右侧面板内部接缝平直；右侧、底部留白减半。浏览器等卡片打开时继续沿用既有铺满视口的行为，关闭后恢复 2px 留白。继承 0.6.22 的输入区隐藏／等待选择宽度保护。

## 更新方式

- 有更新时，左栏头像上方显示橙色入口；无更新或安装完成后隐藏。
- 默认自动检查和下载，安装需要明确选择。
- “设置 → 更新中心”可手动检查，仓库填写 `Math-rookie/dsh-codex-ui`。
- 每次安装前生成报告。失败项阻止安装，未验证项目需要展开查看并明确确认。

从 [Releases](https://github.com/Math-rookie/dsh-codex-ui/releases) 下载 `.tgz`，通过 Harness 插件管理器首次安装。已有更新中心的用户可直接检查更新。0.1.0 用户需先手动安装更新中心 0.1.1 的下载修复包。

已有鲸鱼背景适配插件时，先更新适配插件 0.2.2，再重新检查并查看新报告，更新主界面 0.6.23。更新中心只更新已安装插件，不会因清单额外列出适配插件而自动新增它。安装前先处理内存中的临时侧聊，确认没有运行或待确认的会话。

“设置 → Codex UI”含下一句预测开关与模型设置；执行依赖单独的 `@local/codex-prompt-suggestions`，本 Release 不含该插件。
